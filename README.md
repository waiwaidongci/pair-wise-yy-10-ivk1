# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

## 业务文件拆分

- `js/rules.js` —— 规则层（纯逻辑）：样稿确认单、改样变更单、工序流转守卫、缺陷追加、履历组装。
- `js/storage.js` —— 存储层：localStorage 唯一读写入口，含旧版数据（`zfl42Works`）自动迁移与示例数据。
- `js/page.js` —— 页面层：看板/履历渲染、表单与弹窗，所有数据变更都走规则层。
- `index.html` —— 结构与样式。

## 样稿确认与改样规则

- 新增作品即生成并绑定 v1 样稿确认单（需登记联系人）；作品必须绑定当前**已确认**样稿才能继续阴干和交付，否则返回 409。
- 改动纹样、胎体或线条须新建变更单，登记联系人、当前样稿版本、原因和改后内容：
  - 旧确认单立即失效（只读留档），作品停在「待复确认」，期间禁止任何工序流转；
  - 缺项、版本不一致、样稿无变化均返回 409；
  - 每件作品同时只能有一份未确认变更，重复或并发请求沿用首次登记，不产生新单。
- 复确认通过后生成下一版本确认单（v2、v3……），应用新样稿并恢复变更前工序；也可撤回变更让原确认单重新生效（变更单仍留档）。
- 旧版本确认单与全部变更单只追加、不可改；缺陷按条目追加，流转记录形成只读履历时间线。

## 其他功能

- 工序看板：贴线中、待复确认、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表；筛选、排序、JSON 导出。
- localStorage 持久化（键 `zfl42State.v1`），刷新后看板与履历一致。
